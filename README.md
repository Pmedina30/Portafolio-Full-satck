# 💼 Portafolio Full-Stack — Pablo Medina

Colección de 4 aplicaciones web profesionales, interactivas y listas para producción, demostrando dominio en desarrollo **Full-Stack**, arquitecturas modernas, bases de datos SQL y NoSQL en la nube, animaciones 3D WebGL, e interfaces de usuario de alto impacto.

---

## 🌟 Proyectos Destacados del Portafolio

### 1. 🏪 ColmadoPro — Sistema Integral de Ventas, Inventario & KPIs
> **Stack:** React 18, Vite, Tailwind CSS, Firebase Authentication, Cloud Firestore, Recharts, Lucide Icons.

- **Descripción:** Plataforma moderna de gestión comercial para colmados y tiendas de autoservicio.
- **Aspectos Destacados:**
  - 🔐 **Autenticación Multi-Método:** Firebase Auth (Email/Contraseña + Google Sign-In) y botón directo **Power User (Pablo Medina - Admin)** con privilegios completos.
  - 📊 **Dashboard Ejecutivo:** KPIs de facturación en Pesos Dominicanos (RD$), margen de ganancia neta, volumen de órdenes y gráfico interactivo semanal con **Recharts**.
  - 🛒 **Punto de Venta (POS):** Catálogo con búsqueda predictiva, carrito con validación de stock, métodos de pago (Efectivo con cálculo de devuelta, Tarjeta, Transferencia) y generación de recibo digital imprimible.
  - 📦 **Control de Inventario:** CRUD completo, alertas automáticas de existencias críticas (🟡 Bajo / 🔴 Agotado), entrada rápida de mercancía y exportación a **CSV**.
  - 🔄 **Sincronización Dual:** Soporta Cloud Firestore en la nube o modo interactivo local persistente.
- **Lanzador 1-Click:** `run_colmado.bat` (Puerto: `http://localhost:5175`)

---

### 2. 🎧 NEXUS-01 — 3D Cybernetic Audio Experience
> **Stack:** React 18, Three.js, WebGL, Tailwind CSS, Web Audio API, Vite.

- **Descripción:** Landing page viral de comercio electrónico tecnológico inspirada en los lanzamientos de hardware de Apple y Cyberpunk.
- **Aspectos Destacados:**
  - 🌐 **Animación Scroll-Driven 3D:** Desensamble cinematográfico de auriculares (exploded view) conforme el usuario hace scroll, revelando diafragmas acústicos de titanio y procesador neuronal.
  - 🎨 **Personalizador PBR en Tiempo Real:** Cambio instantáneo de materiales (Obsidian Cyber, Titanium Silver, Neon Cyan, Galactic Purple) con reflejos e iluminación de estudio dinámica.
  - 🔍 **Modo Inspección 360°:** Control de cámara libre orbital mediante mouse/touch.
  - 🔊 **Sintetizador Ambiental:** Audio procedimental interactivo generado con la Web Audio API.
- **Lanzador 1-Click:** `run_nexus.bat` (Puerto: `http://localhost:5174`)

---

### 3. 🦷 SmileCraft Dental — Clínica Odontológica Full-Stack
> **Stack:** React 18, Tailwind CSS, Python (Flask), SQLite, JWT, REST API, Vite.

- **Descripción:** Plataforma integral para consultorios dentales con portal de pacientes y panel médico.
- **Aspectos Destacados:**
  - 🩺 **Catálogo Médico:** Servicios odontológicos, cuadro de especialistas y cotizaciones.
  - 🔐 **Autenticación JWT:** Sesiones seguras con control de acceso por roles (Paciente y Odontólogo).
  - 📅 **Agendamiento:** Reservas de citas en tiempo real con historial médico y tratamientos.
  - 🧪 **API REST en Python:** Backend desacoplado con endpoints probados bajo suites de testing automatizadas.
- **Lanzador 1-Click:** `run_dental.bat` (Frontend: `5173`, Backend: `5001`)

---

### 4. 🐍 PyStack — Portal Web & Sistema de Autenticación en Python
> **Stack:** Python, Flask, SQLite, HTML5, Modern CSS Grid & Variables.

- **Descripción:** Aplicación base de arquitectura limpia enfocada en seguridad y rendimiento backend.
- **Aspectos Destacados:**
  - 🔒 **Seguridad Criptográfica:** Hashing de contraseñas con algoritmo `PBKDF2-SHA256` y protección contra inyecciones SQL.
  - 👤 **Gestión de Cuentas:** Registro, login con validaciones dinámicas, botón de autocompletar credenciales de prueba y dashboard de perfil.
  - ⚡ **Cero Dependencias Pesadas:** CSS nativo puro y responsivo con variables CSS.
- **Lanzador 1-Click:** `run.bat` (Puerto: `http://127.0.0.1:5000`)
